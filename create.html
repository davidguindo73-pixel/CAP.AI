Backend setup / documentation

Deploy the api/ folder as a Node 20+ web service. On Render: root directory api, build command npm install, start command npm start. Add allowed website origins under CORS_ORIGINS. Read the backend setup guide and copy the example environment settings from api/.env.example. The backend is separate from GitHub Pages because Pages only serves static files.
