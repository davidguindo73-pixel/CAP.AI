Privacy

Privacy notice for the preview.

Interim notice · October 2026.

Draft only: Early draft: review this before public launch or paid use. When you request generation, your prompt and any chosen reference file are sent to the configured model provider.

Local storage

Optional profile details, saved prompt drafts, the API base URL and a random browser-session identifier can be stored in this browser's local storage. They are not synced to a CAP.AI account. The provider API key and private access token fields are not intentionally saved by CAP.AI. Clearing browser data can erase local settings and drafts.

Reference media

Before generation, a selected reference is previewed locally. When you click Generate media, the browser asks the configured CAP.AI API for a signed upload URL and sends the file to the selected provider for processing. The provider’s own terms and privacy notice govern its handling and retention. The CAP.AI prototype keeps request IDs, workflow metadata and a one-way ownership hash in temporary server memory; jobs can be lost when the API restarts. CAP.AI does not intentionally persist the raw provider API key or generated media assets.

Hosting and third parties

The homepage loads Tailwind CSS and Google Fonts through CDNs; the host and CDNs may receive technical request data under their own policies. This preview does not intentionally add CAP.AI analytics.

Before production

The API key you enter is sent to the configured backend over HTTPS for provider requests and is not intentionally logged or stored by this prototype. Do not upload confidential, sensitive or personal material until a production data-retention, deletion and security process is published. The provider may process data under its own policies. This is an interim notice, not legal advice. Use Contact for public feedback; do not post sensitive info.
