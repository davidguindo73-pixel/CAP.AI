Privacy

Privacy notice for the preview.

Interim notice · October 2026.

Draft only: Update this before production models, accounts, analytics, uploads or payments.

Local storage

Optional profile details and saved prompt drafts live in this browser's local storage. They are not synced to a CAP.AI account. Clearing browser data can erase them.

Reference media

Studio uses a local object URL to preview media. This site does not send reference files to a CAP.AI model because generation is not connected.

Hosting and third parties

The homepage loads Tailwind CSS and Google Fonts through CDNs; the host and CDNs may receive technical request data under their own policies. This preview does not intentionally add CAP.AI analytics.

Before production

Before accounts, model providers, uploads or payments launch, explain data categories, purposes, retention and deletion. This is an interim notice, not legal advice. Use Contact for public feedback; do not post sensitive info.
