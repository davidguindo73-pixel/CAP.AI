Honest claims.

Proposed principles for responsible AI creative workflows.

Transparency

Distinguish mockups from model outputs and state whether a feature prepares prompts or generates media.

Human control

Creators should choose prompts, review outputs and understand which settings affect results.

Consent and dignity

Respect people's rights and privacy. Do not build features for non-consensual intimate imagery, deceptive impersonation or harassment.

Data minimization

Collect only data needed for a stated purpose. Document retention/deletion before uploads and never expose API keys in browser code.

Clear economics

Publish real prices and limits only after implementation. Explain model-call costs before purchase.

Status

These principles are not certifications or proof that every safeguard exists. See the Changelog.
