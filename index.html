— Questions

What to know about this preview.

Can CAP.AI generate images or video yet?+
Not yet. This version is a website and prompt-builder preview. Real generation requires connecting image and video model APIs.
What does the Prompt Lab do?+
It combines your idea with a chosen output type and visual style to create a detailed prompt that you can copy into another compatible tool.
Can I upload reference images?+
The studio can preview reference files locally and prepare editing prompts. Actual generation needs a connected AI model.
How much does it cost?+
There is no paid plan in this preview. Pricing will be published when the product features and payment flow are ready.
